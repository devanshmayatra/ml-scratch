###2. The Standard Project Workflow ("The Loop")*Used for every mini-project to build reliable systems.*

1. **The Setup (Hardware & Determinism)**
* Set `random_state` / Seed.
* Select Device (`cuda` vs `cpu`).
* Define Strategy (`Stratified K-Fold`).


2. **The Baseline (Sanity Check)**
* Run a simple model (Dummy/Defaults).
* *Check:* Does it beat random guessing? If not, fix data.


3. **The Tuning (Optimization)**
* Run `GridSearch` / `RandomSearch`.
* *Niche:* Maximize hardware (`n_jobs=-1`, AMP).


4. **The Diagnostics (Health Check)**
* Check Confusion Matrix.
* Check Confidence (`predict_proba` distributions).
* *Niche:* Identify "Worst Fold" and inspect specific failure points.


5. **The Interpretation (The "Why")**
* Feature Importance / SHAP values.
* *Check:* Ensure model isn't cheating (e.g., using ID columns).


6. **The Serialization (Deployment Prep)**
* Save model (`joblib` / `.pt`).
* Save metadata (scaler logic, class names)
